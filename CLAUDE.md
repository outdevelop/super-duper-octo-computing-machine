# Карго Экспресс — заметки для работы с репозиторием

Сайт перевозки автомобилей автовозом из Владивостока: лендинг, кабинет клиента, админ-панель.
Node.js 22.5+, Express, встроенный SQLite (`node:sqlite`). Подробности — в README.md.

## Проверки перед коммитом

- `npm test` — тесты API должны проходить.
- **Скриншоты обязательно обновлять.** После любого изменения интерфейса (HTML, CSS, клиентский JS,
  тексты, данные, влияющие на вид страниц) запусти `npm run screenshots` и закоммить изменённые файлы
  `docs/screenshots/*.png` вместе с кодом. Скрипт падает с ошибкой, если на странице есть ошибки JS
  или элементы вылезают за край экрана — такие ошибки нужно исправить, а не игнорировать.
- Если добавлена новая страница или раздел — добавь его снимок в `scripts/screenshots.js`
  и при необходимости в галерею в README.md.
- Просматривай свежие скриншоты глазами: скрипт проверяет ошибки, но не дизайн.

## Соглашения

- Интерфейс и тексты — на русском. Комментарии в коде — на русском.
- CSP запрещает inline-стили и скрипты: стили задаются классами или через CSSOM (`el.style.x = ...`).
- Цвета — только через CSS-переменные в начале `public/styles.css` (`--accent` — голубой акцент).
- Тарифы и контакты хранятся в БД и редактируются в админке; `public/tariffs.js` — расчёт и значения по умолчанию.
- Изменения схемы БД — только новой миграцией в конце массива `MIGRATIONS` в `server/db.js`.
