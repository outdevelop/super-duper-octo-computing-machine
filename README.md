# Карго Экспресс — перевозка автомобилей автовозом из Владивостока

Сайт компании: лендинг с калькулятором стоимости и личный кабинет с регистрацией, заказами и отслеживанием статуса.
Чёрно-белый дизайн, адаптив под телефоны.

> Телефоны, адрес, цифры автопарка и тарифы — заглушки. Замените их на свои (см. ниже).

## Что есть

**Лендинг** (`public/index.html`)
- Первый экран, калькулятор стоимости (город, тип авто, опции), шаги работы, преимущества,
  таблица направлений, автопарк, FAQ, форма обратного звонка.
- Кнопка «Оформить заказ» в калькуляторе переносит выбранные параметры в личный кабинет.
- Заявки из формы сохраняются в БД и видны менеджеру.

**Личный кабинет** (`public/account.html`)
- Регистрация и вход по email и паролю.
- Клиент: создание заказа (цену считает сервер), список заказов, карточка заказа с прогрессом
  и историей статусов, отмена новой заявки, редактирование профиля, смена пароля.
- Менеджер: все заказы с фильтром по статусу, данные клиента, смена статуса с комментарием
  (клиент видит его в истории), заявки с сайта, сводная статистика.

## Запуск

Нужен **Node.js 22.5+**: база данных — встроенный `node:sqlite`, нативных модулей нет.

```bash
npm install
npm run create-manager -- manager@example.com 'надёжный-пароль' 'Анна'
npm start            # http://localhost:3000
```

- `npm run dev` — перезапуск сервера при изменениях.
- `npm test` — тесты API.

База создаётся автоматически в `data/app.db` (папка в `.gitignore`, её нужно бэкапить).

### Переменные окружения

| Переменная    | По умолчанию   | Назначение |
|---------------|----------------|------------|
| `PORT`        | `3000`         | Порт сервера |
| `DB_PATH`     | `data/app.db`  | Путь к файлу SQLite |
| `NODE_ENV`    | —              | `production` включает флаг `Secure` у cookie (нужен HTTPS) |
| `TRUST_PROXY` | —              | `true` или `1`, если сервер стоит за nginx/балансировщиком |

## Безопасность

- Пароли хэшируются через scrypt с солью; сравнение за постоянное время.
- Сессии: случайный токен в `HttpOnly`, `SameSite=Lax` cookie, в БД хранится только его SHA-256; срок — 30 дней.
  Смена пароля завершает остальные сессии.
- CSRF: изменяющие запросы принимаются только как `application/json` и только с того же origin.
- Ограничение частоты для входа, регистрации, заявок и заказов (10 в минуту).
- Заголовки CSP, `X-Frame-Options`, `nosniff`; весь пользовательский ввод экранируется при выводе.
- Клиент видит только свои заказы; цена заказа всегда пересчитывается на сервере.

## Как поменять контент

- **Тарифы, города, типы авто, опции, статусы** — `public/tariffs.js`. Этот файл используют
  и калькулятор, и сервер, поэтому цены везде совпадут.
- **Название, телефоны, адрес, мессенджеры** — поиск по `Карго Экспресс`, `КАРГО`, `+7 (900) 000-00-00`,
  `info@example.com`, `ул. Примерная` в `public/*.html`.
- **Цвета и шрифты** — переменные в начале `public/styles.css`.

## Структура

```
public/            статика: лендинг, кабинет, стили, скрипты, tariffs.js
server/index.js    Express-приложение, заголовки безопасности, раздача статики
server/api.js      REST API: auth, профиль, заказы, заявки, статистика
server/auth.js     пароли, сессии, лимитер запросов
server/db.js       схема SQLite
scripts/           создание менеджера
test/              тесты API (node:test)
```

## API

| Метод | Путь | Доступ |
|-------|------|--------|
| POST | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | все |
| GET / PATCH | `/api/me` | пользователь |
| POST | `/api/me/password` | пользователь |
| GET / POST | `/api/orders` | пользователь (менеджер видит все, `?status=`) |
| GET | `/api/orders/:id` | владелец или менеджер |
| POST | `/api/orders/:id/cancel` | владелец, только статус `new` |
| PATCH | `/api/orders/:id/status` | менеджер |
| POST | `/api/leads` | все |
| GET, PATCH | `/api/leads`, `/api/leads/:id` | менеджер |
| GET | `/api/stats` | менеджер |
